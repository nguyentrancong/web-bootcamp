# React + TypeScript + Vite

1. State Management (Quản lý trạng thái)

   • Redux: Giúp quản lý trạng thái toàn cục của ứng dụng một cách rõ ràng và dễ dự đoán.
   • Redux Toolkit: Bản nâng cấp của Redux với cấu trúc rõ ràng, đơn giản hơn.
   • MobX: Quản lý trạng thái dựa trên lập trình hướng đối tượng, thích hợp cho các ứng dụng có cấu trúc phức tạp.
   • Recoil: Thư viện quản lý trạng thái nhẹ, dễ tích hợp và có API hiện đại hơn Redux.

2. Data Fetching (Lấy dữ liệu)

   • Axios: Giúp gửi HTTP requests một cách dễ dàng với cấu trúc API đơn giản.
   • React Query: Quản lý dữ liệu từ các API một cách tối ưu, hỗ trợ caching và làm mới dữ liệu tự động.
   • SWR: Tương tự React Query, nhưng nhẹ hơn và dễ tích hợp, phù hợp với các dự án nhỏ.

3. Routing (Điều hướng)

   • React Router: Thư viện điều hướng phổ biến nhất, hỗ trợ routing phức tạp và có tính năng quản lý session.

4. Form Handling (Xử lý biểu mẫu)

   • Formik: Hỗ trợ xử lý form với nhiều tính năng như validation, quản lý state của form.
   • React Hook Form: Nhẹ, dễ dùng và tận dụng được các tính năng của hook trong React để quản lý biểu mẫu.
   • Yup: Thư viện chuyên dùng cho việc validation dữ liệu, thường được kết hợp với Formik hoặc React Hook Form.

5. UI Component Libraries (Thư viện giao diện người dùng)

   • Material-UI (MUI): Cung cấp các component giao diện theo phong cách Material Design.
   • Ant Design: Bộ giao diện phổ biến với nhiều component, phù hợp cho các ứng dụng quản lý.
   • Chakra UI: Hỗ trợ các component có thể tùy biến mạnh mẽ và tối ưu hóa cho dark mode.
   • Tailwind CSS: Thư viện CSS utility-first, giúp xây dựng giao diện nhanh chóng mà không cần viết CSS từ đầu.

6. Animation (Hiệu ứng động)

   • Framer Motion: Thư viện animation với API mạnh mẽ, dễ dùng cho cả những animation phức tạp.
   • React Spring: Cung cấp các hiệu ứng vật lý tự nhiên hơn, phù hợp với animation mượt mà.

7. Testing (Kiểm thử)

   • Jest: Thư viện kiểm thử phổ biến cho JavaScript và React, hỗ trợ snapshot testing.
   • React Testing Library: Cung cấp các công cụ kiểm thử dựa trên cách người dùng tương tác với giao diện.
   • Cypress: Thư viện kiểm thử end-to-end (E2E) mạnh mẽ, giúp mô phỏng hành động của người dùng trên trang web.

8. Utilities (Tiện ích khác)

   • Lodash: Thư viện utility với nhiều hàm tiện ích, giúp xử lý dữ liệu hiệu quả hơn.
   • Moment.js / date-fns: Xử lý và định dạng ngày tháng dễ dàng.
   • classnames: Hỗ trợ quản lý và kết hợp các class CSS có điều kiện.
   • Immer: Hỗ trợ thay đổi bất biến với state của Redux một cách dễ dàng.

9. Code Quality (Chất lượng mã nguồn)

   • ESLint: Kiểm tra và chuẩn hóa mã nguồn, giúp phát hiện lỗi trong quá trình phát triển.
   • Prettier: Tự động định dạng mã nguồn, giúp mã nhất quán và dễ đọc.

10. i18n (Đa ngôn ngữ)

    • react-i18next: Thư viện i18n phổ biến nhất cho React, dễ cấu hình và tích hợp.

11. SEO (Tối ưu hóa công cụ tìm kiếm)

    • React Helmet: Quản lý các thẻ meta, title để tối ưu SEO cho ứng dụng React.
